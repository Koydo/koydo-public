# Security

Please do not report security issues in public GitHub issues.

Koydo's production code and infrastructure repositories are private. This public repository contains general information only.

If you believe you have found a security issue in a Koydo public surface, contact Koydo through the public website or LinkedIn page with a concise description of the issue and where it appears.

Do not include secrets, personal data, learner data, or exploit details in public posts.
