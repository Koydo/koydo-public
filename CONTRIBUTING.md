# Contributing

Koydo is not accepting broad public code contributions in this repository yet.

Public contributions may be considered later for documentation, curriculum principles, accessibility notes, localization review, and community feedback.

For now, please use public Koydo contact channels for partnership or collaboration inquiries.

## Contribution Expectations

Future public contributions should be:

- respectful and learner-centered
- safe for families, schools, and public reviewers
- free of secrets, private data, or confidential material
- clear about whether they are suggestions, corrections, or proposals
