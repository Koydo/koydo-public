# Public Principles

Koydo's public work is guided by a few practical principles.

## Learning Should Be Useful

Learning tools should help learners practice, understand, remember, and keep going. Features should earn their place by improving the learner experience.

## AI Should Serve the Learner

AI should support explanation, practice, feedback, accessibility, and adaptation. It should not hide uncertainty, replace human judgment where it matters, or make learning feel less human.

## Multilingual Access Matters

High-quality learning should not assume one language, one device, or one ideal learning environment.

## Curriculum Should Be Explainable

Learning paths, skills, prerequisites, and outcomes should be structured in ways that educators, families, partners, and learners can inspect and understand.

## Safety and Privacy Are Core Requirements

Learner trust requires clear boundaries, careful data handling, age-appropriate design, and respectful feedback.
