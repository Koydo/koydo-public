# Public Boundaries

This repository is intentionally limited to public-safe information.

## Public-Safe

- Koydo mission and positioning
- public links
- general learning principles
- high-level curriculum and accessibility commitments
- public contribution expectations
- broad product category descriptions

## Not Public Here

- production application source code
- private platform architecture
- provider IDs or service configuration
- API keys, tokens, secrets, or environment variables
- internal launch plans or pricing assumptions
- learner records or analytics
- unpublished partner, school, ministry, or customer information

## Review Standard

Before adding public material, check that it would be appropriate for families, schools, reviewers, regulators, partners, and learners to read without exposing internal implementation details.
